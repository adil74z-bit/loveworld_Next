# Roadmap

Each phase is finished and tested before the next one starts.

| Phase | Goal | Status |
| --- | --- | --- |
| 0 | Clean foundation: Vite, Three.js, Firebase skeleton, docs | Files written. Not yet run in a browser (see below) |
| 1 | Google login + permanent Player ID + cloud profile | Not started |
| 2 | Character creator at first registration, saved to cloud | Not started |
| 3 | Lobby: profile, Play, Settings, Edit Character | Not started |
| 4 | Explorable 3D island + desktop/mobile controls | Not started |
| 5 | Interactive objects, furniture, decoration | Not started |
| 6 | Save world changes and progress to Firebase | Not started |
| Later | Multiplayer (architecture kept ready, not built) | Not planned yet |

## Phase 0 testing checklist (do this yourself)

- [ ] `npm install` finishes without errors
- [ ] `npm run dev` starts and the page opens
- [ ] A spinning pink cube on green ground appears
- [ ] FPS shows bottom-left
- [ ] Works when opened on a phone (same Wi-Fi)
- [ ] `npm run build` finishes without errors

Tick a box only after you have actually seen it work.
