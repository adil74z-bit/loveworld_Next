
# Love World – 3D Models

This folder contains the original 3D models used in the Love World game.

## Main Island Map

- File: `LoveWorld_Detailed_Compact_Island.glb`
- Format: GLB (glTF Binary)
- Purpose: Main explorable island environment.
- Usage: Loaded into the game using Three.js GLTFLoader.

## Map Contents

- Turquoise ocean
- Grassy island and sandy beaches
- Luxury villa and swimming pool
- Garden and walking paths
- Trees, flowers and greenery
- Roads, promenade and decorative objects
- Pier and beach environment

## Important Instructions

- Keep the original model file unchanged.
- Do not delete or rename the main island model without updating the game loader.
- All future 3D character models should be managed separately.
- Optimize models before adding large additional assets.
